六爻案例 019: 走失的猫能否找回

求测者信息

关系: 求测人(女,24岁,独居)
事项: 养了三年的猫从前天跑出去没回来,问能不能找到
起卦时间: 2024 年 7 月 22 日未时
起卦方式: 手动摇卦
结果: 三天后在小区楼下花坛的灌木丛里找到,猫受了惊,缩在里面不敢出来

起卦信息

本卦: 山火贲(艮上离下)
变卦: 山天大畜(艮上乾下)
动爻: 九三(兄弟辰土动变父母午火)

用神分析

寻宠物,宠物取子孙爻(子孙代表小动物、宠物)。但这个卦里子孙爻没有上卦,需要找伏神。

子孙巳火伏在二爻官鬼寅木之下:
- 飞来生伏 → 寅木生巳火 → 伏神得出
- 子孙伏藏 → 猫躲起来了,没走远
- 伏在官鬼之下 → 猫受了惊吓,害怕

这就像一个小孩躲进衣柜里。他没丢,就在家里某个角落。你喊他,他不敢出来。

位置判断

子孙伏在内卦(二爻):
- 内卦为家内/近处 → 猫在附近
- 二爻为宅 → 就在家附近

寅木为东北方,但伏藏,不在明面。在低处、隐蔽的地方。

动爻分析

三爻兄弟辰土动变父母午火:
- 兄弟动 → 有变动,有人/物移动过
- 辰土为龙,也代表土、花坛、泥地
- 变父母午火 → 父母主遮蔽物,午火为南方

辰土动,提示方向和环境。辰为东南方,土中。结合"花坛""灌木丛"这类意象。

应期分析

子孙巳火伏藏:
- 巳火得出需要冲飞或克飞
- 申日(金)冲寅木(飞神) → 伏神得出
- 从7月22日起,7月25日是乙巳日 → 子孙值日,猫出现

三天左右能找到。巳日或申日是关键应期。

卦象分析

山火贲,山下有火。"贲"是装饰、掩盖的意思。东西被遮住了。

变山天大畜,山下有天。"大畜"是大积蓄、大收藏。东西被收起来了,没有丢。

综合判断

四个线索指向"能找到":
1. 子孙伏在内卦 → 猫在近处
2. 飞来生伏 → 伏神有出头之日
3. 变卦大畜 → 东西被收着,没丢
4. 应期三天内 → 很快就能找到

结论: 猫没走远,就在小区里。受了惊躲起来了。三天内能找到。

应验

7月25日(乙巳日)下午,邻居大妈在楼下花坛灌木丛里发现一只缩成一团的猫。求测人下去一看,就是她的猫。猫浑身发抖,估计被野狗追过。灌木丛在家楼下的东南方向,低矮、隐蔽。

判断准则提炼

L53 寻宠物 → 子孙爻为用神
L54 子孙伏藏内卦 → 宠物在近处,没走远
L55 飞来生伏 → 伏神得出,能找到
L56 变卦大畜 → 东西被收藏,没丢失
L57 应期 → 冲飞或值日之日

反例风险

- 子孙伏藏不代表一定在家附近,要看飞神位置和动爻指向
- 飞来生伏是好信号,但如果日月克伏,可能拖延很久
- 变卦大畜是"收藏"意象,但如果是"归墓"可能就找不到了
