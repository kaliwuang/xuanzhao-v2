用神规律总结

六爻取用神,核心就一句话: 看你问什么,取什么。

婚姻占:
- 男问妻 → 妻财爻
- 女问夫 → 官鬼爻
- 案例 005 女问婚 → 取官鬼酉金(伏藏但得出)

求职/升职/事业:
- 职位 → 官鬼爻
- 文书/调令/通知书 → 父母爻
- 案例 001(考博)取父母,案例 002(入职)取官鬼,案例 009(升职)取官鬼

投资/求财:
- 钱 → 妻财爻
- 财源 → 子孙爻
- 劫财 → 兄弟爻
- 案例 006 投资 → 财爻被合泄+兄弟持世

疾病:
- 自己 → 世爻
- 病症 → 官鬼爻
- 医药 → 子孙爻
- 案例 007 → 官鬼安静+子孙伏藏有救

寻物:
- 财物 → 妻财爻
- 证件文书 → 父母爻
- 案例 008 手机 → 父母爻被合住

判断结果的三条路

路一: 用神旺相 + 世爻有力 → 成
- 案例 005(婚): 官鬼虽伏但得出,世爻有根
- 案例 009(升职): 官鬼旺相,世爻旺相

路二: 用神衰弱 + 世爻受克 → 不成
- 案例 002(入职): 官鬼弱,世应相克

路三: 用神有救 → 虽险但成
- 案例 007(健康): 官鬼休囚,子孙伏藏但有出头日
- 案例 001(考博): 父母爻旺,应期精准

世应关系的实战意义

世应相生 → 双方配合,事情顺
- 案例 005: 世生应+应生世 → 婚姻双方互有好感

世应相克 → 对方跟自己对着干
- 案例 002: 世应相克 → 入职失败

世爻旺 → 自己状态好,有竞争力
- 案例 009: 世爻酉金旺 → 升职有戏

动爻的实战解读

动爻就是"变数"。动了就说明这件事不是静止的,有变化。

动爻生用神 → 好变化
- 案例 009: 父母动生官鬼 → 文书催生职位

动爻克用神 → 坏变化
- 案例 006: 子孙动化兄弟 → 财源变消耗

动爻在内卦 → 变数来自内部
- 案例 008: 动爻在内卦 → 东西在家内

动爻在外卦 → 变数来自外部

应期判断的规律

应期 = 用神当旺/临值/被合解之日

日级应期:
- 案例 001: 壬午日(午火生父母)→ 当天收到

月级应期:
- 案例 005: 酉月(官鬼当旺)→ 订婚
- 案例 009: 巳午月(官鬼得助)→ 任命

给应期的原则:
- 短期事件(考试/出行) → 给日
- 中期事件(求职/婚姻) → 给月
- 长期事件(投资/事业) → 给季

六爻实战的核心心法

一句话: 用神定方向,世爻看实力,动爻看变化,应期看旺衰。

你问的事情能不能成,取决于:
1. 用神旺不旺(事情本身有没有戏)
2. 世爻强不强(你自己有没有能力接住)
3. 动爻帮不帮(有没有外力推动)
4. 应期到不到(什么时候兑现)

四条都指向"好"→ 肯定成
四条都指向"坏"→ 肯定不成
有好有坏 → 看哪条力量更大
