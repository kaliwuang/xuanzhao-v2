用神规律总结

六爻取用神,核心就一句话: 看你问什么,取什么。

婚姻占:
- 男问妻 → 妻财爻
- 女问夫 → 官鬼爻
- 案例 005 女问婚 → 取官鬼酉金(伏藏但得出)

求职/升职/事业:
- 职位 → 官鬼爻
- 文书/调令/通知书 → 父母爻
- 案例 001(考博)取父母,案例 002(入职)取官鬼,案例 009(升职)取官鬼

投资/求财:
- 钱 → 妻财爻
- 财源 → 子孙爻
- 劫财 → 兄弟爻
- 案例 006 投资 → 财爻被合泄+兄弟持世
- 案例 016 合伙 → 兄弟持世动+财伏被克

疾病:
- 自己 → 世爻
- 病症 → 官鬼爻
- 医药 → 子孙爻
- 案例 007 → 官鬼安静+子孙伏藏有救

寻物/寻宠物:
- 财物 → 妻财爻
- 证件文书 → 父母爻
- 宠物 → 子孙爻
- 案例 008 手机 → 父母爻被合住
- 案例 019 猫 → 子孙伏内卦,飞来生伏

天气:
- 雨 → 父母爻
- 晴 → 妻财爻
- 风 → 兄弟爻
- 太阳 → 子孙爻
- 案例 018 → 父母旺动+日月水旺

搬家:
- 综合看世爻+应爻(新环境)+动爻
- 案例 017 → 世旺+应生世+子孙变财

判断结果的三条路

路一: 用神旺相 + 世爻有力 → 成
- 案例 005(婚): 官鬼虽伏但得出,世爻有根
- 案例 009(升职): 官鬼旺相,世爻旺相
- 案例 017(搬家): 世旺+应生世

路二: 用神衰弱 + 世爻受克 → 不成
- 案例 002(入职): 官鬼弱,世应相克
- 案例 016(合伙): 财伏被克,兄弟持世

路三: 用神有救 → 虽险但成
- 案例 007(健康): 官鬼休囚,子孙伏藏但有出头日
- 案例 001(考博): 父母爻旺,应期精准
- 案例 019(寻宠物): 子孙伏藏但飞来生伏

世应关系的实战意义

世应相生 → 双方配合,事情顺
- 案例 005: 世生应+应生世 → 婚姻双方互有好感

世应相克 → 对方跟自己对着干
- 案例 002: 世应相克 → 入职失败

世爻旺 → 自己状态好,有竞争力
- 案例 009: 世爻酉金旺 → 升职有戏
- 案例 017: 世爻未土旺 → 搬家后底子好

应生世 → 外部环境对自己有利
- 案例 017: 午火生未土 → 新环境帮自己

动爻的实战解读

动爻就是"变数"。动了就说明这件事不是静止的,有变化。

动爻生用神 → 好变化
- 案例 009: 父母动生官鬼 → 文书催生职位

动爻克用神 → 坏变化
- 案例 006: 子孙动化兄弟 → 财源变消耗

动爻在内卦 → 变数来自内部
- 案例 008: 动爻在内卦 → 东西在家内
- 案例 019: 动爻在内卦 → 猫在近处

动爻在外卦 → 变数来自外部

动爻变出财 → 财运来
- 案例 017: 子孙动变妻财 → 搬家后财运好

动爻两现 → 信号加倍
- 案例 018: 父母两现 → 确定下雨

应期判断的规律

应期 = 用神当旺/临值/被合解之日

日级应期:
- 案例 001: 壬午日(午火生父母)→ 当天收到
- 案例 019: 乙巳日(子孙值日)→ 猫出现

月级应期:
- 案例 005: 酉月(官鬼当旺)→ 订婚
- 案例 009: 巳午月(官鬼得助)→ 任命

给应期的原则:
- 短期事件(考试/出行/寻物) → 给日
- 中期事件(求职/婚姻) → 给月
- 长期事件(投资/事业/搬家) → 给季

六爻实战的核心心法

一句话: 用神定方向,世爻看实力,动爻看变化,应期看旺衰。

你问的事情能不能成,取决于四个东西:
1. 用神旺不旺(事情本身有没有戏)
2. 世爻强不强(你自己有没有能力接住)
3. 动爻帮不帮(有没有外力推动)
4. 应期到不到(什么时候兑现)

四条都指向"好"→ 肯定成
四条都指向"坏"→ 肯定不成
有好有坏 → 看哪条力量更大

三个进阶心法:

一、看动不看静。安静的爻信息少,动的爻才是关键。六个爻都安静,事情平淡没有波澜。有爻动了,才有戏看。

二、看克不看生。生的力量是温和的,克的力量是剧烈的。找卦里的"克",往往能找到问题的核心。

三、看伏不看飞。伏藏的东西是隐藏的信息。飞神只是外衣,伏神才是内容。找到伏神,就找到了答案。

六爻最大优势:针对具体事件,给具体答案。八字紫微告诉你"今年财运不好",六爻告诉你"这个投资会亏,不要投"。

六爻最大局限:只能回答一个问题。你摇了一卦问投资,这卦就只管投资,不管婚姻。
