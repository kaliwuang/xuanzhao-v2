六爻案例 009: 问跳槽/升职

求测者信息

关系: 求测人(男,32岁,互联网公司产品经理)
事项: 公司要提拔一个部门经理,他和另一个同事竞争。问能不能升上去
起卦时间: 2024 年 4 月 12 日卯时
起卦方式: 时间起卦
结果: 能升。两个月后正式任命

起卦信息

本卦: 火地晋(离上坤下)
变卦: 火山旅(离上艮下)
动爻: 六五(父母亥水动变兄弟戌土)

用神分析

问升职,用神取官鬼爻(代表职位/权力)。父母爻代表调令/文书。

官鬼爻:

官鬼巳火:
- 巳火在辰月(农历三月) → 火相(有气)
- 日辰未土 → 巳火得日辰生扶
- 官鬼两现(二爻巳火 + 五爻位附近) → 有两个机会/两个候选人

官鬼旺相 → 职位有实权,不是虚职
两个官鬼 → 两个竞争者,符合实际情况

世爻分析

世爻兄弟酉金:
- 酉金在辰月 → 土月金旺
- 世爻旺相 → 求测人状态好,有竞争力

世爻与官鬼的关系:
- 酉金与巳火 → 巳酉半合金局
- 半合 → 有缘分,能搭上关系
- 但不是完全合 → 还需要努力

这就像你和一个好东西之间,隔着一层纱。能看见,也能够着,但得伸手。

动爻分析

五爻父母亥水动变兄弟戌土:
- 父母动 → 调令/文书要来
- 变兄弟 → 文书下来之后,有人帮你(兄弟是同辈/同事)
- 亥水动生官鬼巳火 → 文书催生职位

这个动爻很关键。父母爻动就是"通知要来了"。

综合判断

四个信号指向"能升":
1. 官鬼旺相 → 职位真实存在
2. 世爻旺相 → 自己有实力
3. 世与官半合 → 有缘分
4. 父母动生官 → 文书催生职位

结论: 能升上去。

应期

父母亥水动,亥月(农历十月)或巳月(农历四月)应事。
但辰月起卦,巳月最近。
预测: 两个月内有结果。

实际: 农历五月初正式任命。比预测稍晚一个月。
可能是午月(火旺),官鬼得助,最终落实。

判断准则提炼

L25 事业占 → 用神取官鬼(职位)/父母(文书调令)
L26 官鬼旺相 + 世爻旺相 → 职位有,自己也有竞争力
L27 世与官半合 → 有缘分,能搭上
L28 父母动生官 → 文书催生职位,升职能落实

反例风险

- 两个官鬼不代表两个竞争者,也可能代表两个职位
- 半合不等于全合,中间可能有波折
- 应期有偏差,实战中给"窗口"更稳妥
