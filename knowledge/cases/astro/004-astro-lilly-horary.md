案例四 利利卜卦占星法

问题：王女士，35岁，2024年8月15日下午2点30分（北京时间）问道——"我之前投的那个创业项目，钱能收回来吗？"

这是典型的财务类卜卦问题。按照利利的体系，一步一步来。

问卦时星盘信息

命度：射手座22度
下降点：双子座22度
天顶（MC）：处女座16度
天底（IC）：双鱼座16度

太阳：狮子座22度（7宫附近）
月亮：天蝎座28度（12宫）
水星：处女座5度（9宫）
金星：处女座18度（10宫）
火星：双子座5度（6宫）
木星：双子座27度（7宫）
土星：双鱼座18度（4宫，逆行）

第一步 宫位主星判定

1宫（问卦人）：命度射手座22度。射手座守护星是木星。1宫主星 = 木星。

2宫（财务、投资回报）：2宫头应该在摩羯座附近。摩羯座守护星是土星。2宫主星 = 土星。

但这里有一个要点。王女士问的是"投资的钱能不能收回来"。这不是问自己的钱（2宫），而是问别人欠她的钱或投资回报。这个更接近8宫（他人的钱、投资回报、债务）。8宫头在巨蟹座附近。巨蟹座守护星是月亮。8宫主星 = 月亮。

5宫（投机、投资）也相关。5宫头在白羊座附近。白羊座守护星是火星。5宫主星 = 火星。

所以我们的核心分析对象是：1宫主木星、8宫主月亮、5宫主火星。

第二步 问卦人状态分析

1宫主木星在双子座27度。木星在双子座是"陷"（Detriment）。木星本来庙在射手和双鱼，双子是射手的对面，所以陷。

木星陷落在7宫。7宫是合伙、对手、他人。木星在7宫说明问卦人很关注"对方"（投资方或项目方）的动态。但木星陷落，说明问卦人在这个关系中处境不好，处于弱势。

不过，木星在双子座27度，即将进入巨蟹座（木星旺位）。这意味着事情可能会有转机，但不是马上。像种子刚埋进土里，还没发芽。

第三步 交角分析

这是卜卦占星的灵魂。看月亮的运动轨迹。

月亮在天蝎座28度。天蝎座的守护星是火星，月亮在天蝎座是"陷"的对应位置之一（天蝎不是月亮的传统陷位，但月亮在天蝎偏紧张）。

月亮刚才和谁分开了？看分离角。月亮大约在26度时与冥王星（水瓶座26度）形成了刑相位。冥王星不是古典行星，古典技法中不使用。但我们跳过它。

月亮刚才大约在24度时与土星（双鱼座18度，逆行）形成了六合相位。等等，天蝎24度和双鱼18度是60度吗？24 - 18 = 6，天蝎到双鱼相差4个星座 = 120度。不是六合。再看：天蝎24度和双鱼18度之间是120度三合角吗？天蝎24到双鱼18 = 4个星座差 + 6度差 = 不精确。月亮与土星没有精确的分离角。

月亮刚刚大约在25度时与金星（处女座18度）形成什么角？天蝎25到处女18 = 差7度，两个星座差 = 60度六合角。是的，月亮在25度时与金星18度处女形成了六合角（容许度7度内）。月亮刚刚分离了与金星的六合。

金星在10宫，代表事业运作。月亮（8宫主、他人的钱）分离金星（事业），说明"他人的钱"和"事业"之间刚刚有过一次互动。这正好对应了投资资金流向项目的事实。

月亮下一个应用角是什么？月亮在28度天蝎，即将进入射手座。它在天蝎座最后2度内，需要检查是否与其他行星形成交角。

月亮在29度天蝎时，与火星（双子座5度）形成什么角？天蝎到双子 = 210度 = 不是标准交角。跳过。

月亮进入射手座后，第一个可能的交角是与双子座27度的木星形成冲相位（180度）。月亮从射手0度走到射手27度 = 27度路程。月亮约每小时移动0.5度，需要约54小时（约2天多）。

这就是事情的关键。月亮（8宫主，代表投资回报）将要冲1宫主（木星，代表问卦人自己）。这意味着钱和问卦人之间会有一条通道打开。但是冲相位是紧张的——钱能回来，但过程不愉快、不轻松。

第四步 接纳与传递判断

月亮进入射手座后，月亮在木星的庙位之一（射手是木星的庙）。木星接纳了月亮。

这是好消息。8宫主（投资回报）被1宫主（问卦人）所接纳。说明虽然过程紧张，但结果对问卦人有利。接纳在这里像一张安全网——事情可能磕磕绊绊，但最终不会彻底崩盘。

再看有没有传递光。有没有一颗行星先与月亮形成交角，再与木星形成交角？如果有的话，它就是传递者，把"钱"的能量送到"问卦人"手上。

火星在双子座5度。火星和木星同在双子座（木星27度），但容许度太大（22度），不形成精确交角。

金星刚和月亮分离。金星在处女座18度。金星和木星（双子27度）形成什么角？处女18到双子27 = 差9度，两个星座差 = 60度六合角。容许度9度，偏大，但在临界值附近。

如果金星和木星的应用六合成立，金星就充当了传递者——它从月亮那里接过能量，转手交给木星（问卦人）。金星在10宫（事业、项目方），说明传递通道是通过项目方的运作实现的。

第五步 月亮空亡检查

月亮在天蝎座28度。离开天蝎座之前（进入射手座0度），月亮还有没有与其他行星形成精确交角的机会？

天蝎29度到射手0度只有1度。在这1度里，没有任何行星与月亮形成精确交角。所以月亮在离开天蝎座前最后2度是"空亡"（Void of Course）的。

但月亮在射手座（木星的庙）空亡。按照利利的规则，月亮在金牛、巨蟹、狮子、射手这四个星座空亡时，事情虽慢但有好结果。

这吻合了前面的判断——事情有结果，但要等。

第六步 综合结论

答案是"能收回来，但不快也不全"。

理由如下：

8宫主月亮将冲1宫主木星，冲相位说明过程不轻松。钱能回来，但可能有争议或损失部分。

木星在双子陷落，说明问卦人当前处境不佳，话语权不强。但木星即将进入巨蟹（旺位），说明过一段时间问卦人的处境会改善。

月亮空亡但落在射手（木星庙），事情慢但不会彻底落空。

金星传递月亮能量给木星，通道存在。项目方（金星10宫）会是促成回款的中间人。

具体时间估算：月亮从天蝎28度走到射手27度（冲木星的位置）大约需要2到3天。卜卦占星中一天对应一个月。所以大约2到3个月后会有一笔回款。

但冲相位的紧张性质意味着：可能不是一次全额回来，而是分批。或者回来的过程中需要讨价还价。

给王女士的建议是耐心等待，不要因为着急而放弃或采取激烈手段（冲相位的冲动倾向）。木星即将进入旺位，说明她手里的牌会越来越好。

这套分析方法，就是利利在《基督教占星学》里反复演示的套路。你读他书里的200多个案例，每一条都是这个流程。多读几遍，手感就出来了。像学做菜，菜谱看多了，颠勺的力度自然就有了。
