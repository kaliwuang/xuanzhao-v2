大六壬案例 011: 某人问公务员考试

求测者信息

关系: 求测人(男,26岁,在职备考)
事项: 报了省考某岗位,笔试面试都是关键,问能不能上岸
起课时间: 2024 年 11 月 8 日巳时(甲辰年乙亥月丙寅日癸巳时)
结果: 笔试过了,面试有波折,最终上岸

四课

日干丙火:
- 丙上见甲 → 甲木生丙火(干阳课,日干受生)
- 日支寅木:
- 寅上见子 → 子水生寅木(支阳课,日支受生)

四课分析:
- 干课受生 → 自己有助力(甲木生丙火=有人帮你)
- 支课受生 → 环境有利(子水生寅木=外部条件支持)

干支都受生,这在考试占里是个好信号。就像你去考试,发现监考老师是你熟人,题目又是你复习过的范围。整个环境都在帮你。

但注意: 甲木生丙火,是"印星生身"。印星代表文书、学历、考试运。印星坐干课上,说明考试运本身不错。

三传

初传: 甲木(丙上,生日干)
中传: 丁火(甲木生丁火,再生)
末传: 辛金(丁火克辛金,财星)

三传分析:
- 初传甲木(印星) → 考试运好,笔试能过
- 中传丁火(比肩) → 中间有竞争(丁火=同类=竞争对手)
- 末传辛金(财星) → 最终得财(辛金=结果=收获)

三传的方向: 生→生→克。前两步都是生,只有最后一步是克。

这像跑一千米。前八百米你一直领先,最后两百米有点喘。但你还是跑到了终点。

天将分析

初传甲木乘太常:
- 太常主安稳、正常
- 太常在初传 → 起步平稳,笔试正常发挥

中传丁火乘朱雀:
- 朱雀主文书、口舌
- 朱雀在中传 → 中间环节与文书有关(面试=口舌表达)

朱雀坐中传,面试环节要小心。朱雀代表"说",面试就是看你"说"的能力。丁火乘朱雀,火上加火,容易紧张说错话。

末传辛金乘六合:
- 六合主合和、成就
- 六合在末传 → 最终能合上(考上)

太常→朱雀→六合。这条路是: 稳稳地考→面试有点紧张→最终合上。

贵人位置

丙日贵人在亥(夜贵)和酉(昼贵):
- 起课时间为巳时(昼贵在酉)
- 酉金不在四课三传中,但亥水在月支
- 亥水生寅木,贵人的力量通过月支间接传递

贵人没有直接出现在课中,但通过月支在暗中发力。就像你爸没来考场,但他提前帮你找了辅导老师。

综合判断

五个层面:
1. 四课: 干支都受生 → 环境和自身都有利
2. 三传: 生→生→克 → 前期顺利,后期有压力
3. 天将: 太常→朱雀→六合 → 稳→紧张→成
4. 贵人: 暗中助力(通过月支)
5. 印星坐干课 → 考试运本身就不错

结论: 笔试能过。面试有波折(朱雀在中传,容易紧张),但最终能上岸(六合在末传)。

面试的时候要特别注意口齿表达。朱雀坐丁火,火气太旺,容易话多说错。建议面试前多模拟练习,把话练简练了。

应期

末传辛金,辛金在酉月(农历八月)当旺。
起课时是亥月(农历十一月),要等到来年酉月。
预测: 笔试结果两三个月内出,面试在笔试后一两个月。

实际: 12月底笔试通过。次年3月面试,中间确实紧张了(回答问题时卡壳了一次),但整体表现还行。4月公示,上岸。

判断准则提炼

R34 考试占 → 印星(文书)+朱雀(口舌)+四课干支受生情况
R35 干上神生日干 → 有助力,考试运好
R36 三传生→生→克 → 前期顺利后期有压力,但能成

反例风险

- 印星生身不一定都考得上,还要看印星旺衰
- 朱雀在中传不一定面试差,可能是"面试出名"的好事
- 贵人通过月支间接传递,力量不如直接在课中强
