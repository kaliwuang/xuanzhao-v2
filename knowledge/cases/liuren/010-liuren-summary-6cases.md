四课分析的共性

四课是大六壬的地基。六壬占断,先看四课。

干课看自己:
- 干上神生日干 → 有人帮你
- 干上神克日干 → 有压力/有人为难你
- 干上神与日干合 → 有牵连/有贵人

支课看对方/环境:
- 支上神生日支 → 环境有利
- 支上神克日支 → 环境有阻力
- 支上神与日支冲 → 有冲突

实战对照:
- 案例 006: 干课甲己合 → 贵人扶持 → 升职
- 案例 008: 干克支 → 原告占上风 → 官司赢
- 案例 009: 干课受克 → 有病,但丙火在亥月受制 → 病不重

三传的三种方向

方向一: 生→生→生 → 一路顺
- 暂无此类型案例,说明"一路顺"的案例比较少见(幸存者偏差?)

方向二: 克→生→回 → 先难后易
- 案例 005(出差): 克→生→回 → 有波折但最终成
- 案例 006(升职): 克→冲→回 → 有竞争但最终归己
- 案例 007(感情): 合→生→回 → 先纠缠后理解

方向三: 生→克→克 → 先好后坏
- 暂无此类型案例

三传的方向就像一条路的走向。上坡→下坡→平地,跟下坡→上坡→平地,走起来完全不同。

天将的实战用法

天将不是摆设,每个天将都有明确含义:

| 天将 | 主事 | 出现位置 | 案例 |
|---|---|---|---|
| 青龙 | 喜/行/财 | 中传 | 005(出行有收获) |
| 朱雀 | 文书/口舌 | 中传/末传 | 005(合同)、008(判决) |
| 勾陈 | 官司/缠斗 | 初传 | 008(起因是纠纷) |
| 白虎 | 病症/阻隔 | 初传/末传 | 009(病症)、008(执行阻碍) |
| 天后 | 女性/感情 | 初传 | 007(感情驱动) |
| 天合 | 合和/关系 | 支课 | 007(有合的基础) |
| 天医 | 医药/解救 | 中传 | 009(治疗有效) |
| 太常 | 安稳/平常 | 末传 | 009(回归平常) |
| 玄武 | 暗/欺骗 | 初传 | 005(信息不透明) |

天将出现在不同位置,含义不同:
- 初传 → 事情的起因
- 中传 → 事情的过程
- 末传 → 事情的结果

六壬断不同事项的用神

出行占:
- 看四课干支关系+三传方向+天将(青龙主行/白虎主阻)
- 案例 005

事业占:
- 看贵人位置+三传方向+干课关系
- 案例 006

感情占:
- 看天后(女性)+六合(合和)+四课干支关系
- 案例 002(离婚)、案例 007(复合)

官司占:
- 日干=原告/日支=被告+勾陈(官司)+朱雀(文书)
- 案例 008

疾病占:
- 白虎(病症)+天医(医药)+四课干支关系
- 案例 009

大六壬实战心法

一句话: 四课定格局,三传看走向,天将加细节。

你问的事情怎么样,取决于:
1. 四课干支关系(格局: 谁强谁弱)
2. 三传方向(走向: 从哪来到哪去)
3. 天将出现位置(细节: 什么力量在推动)

三条都指向"好"→ 肯定好
三条都指向"坏"→ 肯定坏
有好有坏 → 看哪条力量更大

大六壬 vs 六爻

| 维度 | 大六壬 | 六爻 |
|---|---|---|
| 分析框架 | 四课三传 | 六亲六神 |
| 天将系统 | 12 天将(贵人体系) | 无(用六亲) |
| 优势 | 格局大,适合复杂事件 | 应期精准,适合单事件 |
| 劣势 | 应期偏差1-3个月 | 格局不如壬课大 |
| 适用 | 官司/出行/合作/复杂决策 | 考试/寻物/单一事件 |
