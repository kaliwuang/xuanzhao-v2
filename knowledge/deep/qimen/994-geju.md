奇门格局详解——吉格与凶格大全

格局就像天气预报里的"晴转多云""暴雨预警"。单一星门神是基础气象，格局是组合出来的天气系统。你得把天盘地盘、八门九星、八神叠在一起看，才能判断出是什么格局。

吉格——天时地利人和的信号

三遁格局（最核心的三组吉格）

天遁：丙奇 + 生门 + 九天（或天盘丙加地盘丁）。你把它想象成"天降横财"——条件齐全的时候，财运特别旺。测投资见天遁，大利。测出行见天遁，一路顺风。

地遁：乙奇 + 开门 + 九地（或天盘乙加地盘己）。像"脚踩实地"——做事踏实、根基稳。测建房、置产、扎根发展，地遁是最好的信号。

人遁：丁奇 + 休门 + 太阴（或天盘丁加地盘乙）。像"贵人相助"——人际关系特别顺。测合作、求人办事、姻缘，人遁大吉。

三遁是奇门里含金量最高的吉格。如果一个盘里同时出现两个或三个遁——叫"三遁并现"——那是至吉之象，非常少见。

龙遁：乙奇 + 开门（或休门） + 天辅星（或九天）。龙遁像一条飞龙在天——主大格局的突破。测事业见龙遁，有升迁或大发展之象。

虎遁：辛 + 杜门（或伤门） + 白虎。别被"虎"吓到。虎遁像猛虎下山——主动出击能赢。在竞争、讨债、军事行动中，虎遁反而大吉。

风遁：乙奇 + 开门 + 天辅星 + 巽宫（东南方）。风遁像顺风行船——出行、传播、扩散类事情特别顺利。测考试信息发布、消息传播，风遁大利。

云遁：乙奇 + 生门 + 天柱星。云遁像云中藏龙——事情暗中有助力。测谋略、暗中操作，云遁主隐蔽得力。

神遁：丙奇 + 生门 + 九天 + 天心星。神遁像神助一般——超乎预期的好结果。测任何事见神遁，都是上上签。

鬼遁：丁奇 + 杜门 + 太阴 + 九地。鬼遁像暗度陈仓——在别人看不见的地方做事。测暗中谋划、秘密行动，鬼遁大利。但测公开的事见鬼遁，反而不妙——事情藏得太深，别人不知道。

飞鸟跌穴格

天盘丙奇加地盘戊。你想象一只鸟从天上掉进了一个舒服的窝里——不费力气就落到好地方。

这是奇门里最经典的吉格之一。主不劳而获、贵人相助、意外之财。测投资见飞鸟跌穴，可能有意外收益。测出行见此格，一路有人照顾。

飞鸟跌穴的核心含义：天上的丙（权威、力量）落到地上的戊（财富、根基）——力量和资源完美结合。

青龙返首格

天盘戊加地盘丙。跟飞鸟跌穴正好反过来。你想象一条青龙回头——已经走远了又回来了。

主失而复得、旧事重来、贵人回头。测感情见青龙返首，旧情人可能回来。测失物见此格，能找回来。

青龙返首和飞鸟跌穴是奇门里一对最著名的"对称吉格"。前者是"戊加丙"，后者是"丙加戊"。两者同时出现叫"龙鸟呈祥"，至吉之象。

天显时格

甲己日的甲子时、甲戌时。或者六甲时辰（甲子、甲戌、甲申、甲午、甲辰、甲寅时）起的局。天显时像"老板亲自出马"——甲不再藏了，直接现身。

天显时格主万事皆宜。不管你测什么，天显时都是好信号。但天显时的局不多见——六天才能遇到一个。

玉女守门格

丁奇落宫正好是值使门所在宫。你想象一个温柔的女子守在门口——有人在等着你来。

主有人等候、事情有人接手、暗中有贵人安排。测办事见玉女守门，去了就有人接待。

仪奇合遁格

乙丙丁三奇中任意两个同时出现在有用之宫（没有被克、没有入墓）。像两个好朋友一起行动——力量翻倍。

主双重吉利、好事成双。如果三奇全部出现在有用之宫，那叫"三奇得使"——最强的吉格配置之一。

三奇得使

乙奇加地盘己或辛，丙奇加地盘戊或庚，丁奇加地盘壬或癸。三奇各自找到了自己的"搭档"。

像三把钥匙各自找到了对应的锁——配合得天衣无缝。三奇得使是"有用之奇"的最高形态。

天辅吉格

天辅星落在吉门（休、生、开）宫，且不被克。天辅星是文星——配上吉门就像一个有才华的人遇到了好机会。

测考试、学习、写作见此格，大吉。

九遁格局小结

除了前面说的天遁、地遁、人遁、龙遁、虎遁、风遁、云遁、神遁、鬼遁这九遁之外，还有一些变体。但九遁是最基础、最常用的吉格框架。

你记住一个规律：吉格的核心就是"好东西碰上好东西"。三奇碰上吉门，吉门碰上吉星，吉星碰上吉神——每多一层好搭配，力量就强一分。

凶格——麻烦来了的信号

太白入荧格（白入荧）

天盘庚加地盘丙。你想象一把刀（庚）砍向一团火（丙）——火被压住了。

主小人当道、被压制、被人欺负。测事业见白入荧，有人在暗中使坏。测感情见此格，第三者插足或被人拆散。

白入荧的核心逻辑：庚是最大的凶干，丙是三奇之一。庚克丙——凶的力量压住了吉的力量。

荧入太白格（荧入白）

天盘丙加地盘庚。跟白入荧反过来。火（丙）烧到了刀（庚）——两败俱伤。

主争斗激烈、鱼死网破。测官司见荧入白，双方撕破脸。测感情见此格，吵架分手。

荧入白在某些情况下比白入荧还凶——因为丙的力量主动出击去克庚，冲突更加激烈。

大格

天盘庚加地盘癸。庚是刀，癸是暗水——刀砍进水里，看不见砍到了什么。

主事情大变、方向不明、计划全乱。测出行见大格，去不成或去了回不来。测投资见此格，血本无归。

小格

天盘庚加地盘壬。庚加壬比庚加癸稍微好一点——壬是大水，至少水面上还看得见。

主事情受阻、计划被打断、但没有大格那么严重。测出行见小格，有波折但能到达。

刑格

天盘庚加地盘己。庚属金，己属土——土生金，看起来是好事。但奇门里"庚加己"叫刑格。

因为己是甲戌旬的替身。庚加己等于"庚金克甲木的替身"——统帅被打，下属受刑。

主犯法、受罚、被处分、身体受伤。测官司见刑格，要吃官司。测健康见此格，有手术或外伤之象。

悖格

天盘丙奇加地盘庚、辛、壬、癸。丙是阳火，碰到庚辛（金被火克）或者壬癸（水克火）——都是对抗性组合。

丙加庚——火克金，主动出击但伤敌一千自损八百。
丙辛——火克金，同上。
丙加壬——水克火，被压制。
丙加癸——水克火，被暗中算计。

悖格总的意思是"违背常理、不按规矩来"。测规矩内的事见悖格，有变故。测创新的事见悖格，反而可能出奇制胜。

五不遇时

时干克日干，而且是阳克阳或阴克阴——同性相克，力量最大。你想象领导被下属正面硬怼——管理失控。

五不遇时主诸事不顺。不管你测什么，遇到五不遇时都得打折。这个时辰起的局，整体格局要降一个等级。

六仪击刑

六仪落在它们的刑冲之地。具体的击刑组合：

戊加辛（子刑卯）
己加壬（戌刑未——不对，这是自刑）
庚加癸（申刑寅——也不完全对）
辛加乙（酉自刑——有的说法）
壬加丙（辰自刑）
癸加丁（寅刑巳）

实际上击刑最常用的组合是：
甲子戊加地盘辛——子刑卯不对，应该是"甲子旬中空亡"的引申。
传统说法：戊在震三宫击刑（子卯刑），己在坤二宫击刑（戌未刑），庚在艮八宫击刑（申寅刑），辛在巽四宫击刑（酉辰刑——有的说法不同），壬在离九宫击刑（辰午自刑），癸在巽四宫击刑（寅巳刑）。

击刑主受伤、痛苦、被惩罚。不管测什么事，用神遇到击刑都不是好信号。

入墓

天盘天干落在它的墓库之地。

乙入戌墓、丙入戌墓、丁入戌墓——三奇全入戌墓。
戊入未墓、己入未墓。
庚入丑墓、辛入丑墓。
壬入辰墓、癸入辰墓。

入墓就像一个人掉进了泥坑——有力量使不出来。测事业见入墓，有才能但施展不开。测出行见入墓，走不了或到了被困住。

空亡

旬空亡。甲子旬空戌亥，甲戌旬空申酉，甲申旬空午未，甲午旬空辰巳，甲辰旬空寅卯，甲寅旬空子丑。

空亡像一个空房间——看起来有门，但里面没人。测事见空亡，事情暂时没有着落。但空亡不是永远空——填实（等到对应的地支值日）就满了。

门迫

八门克它所落宫位的五行。比如伤门（木）落在坤二宫（土）——木克土，门克宫。

门迫像一个强势的人压住了地盘——门的力量被削弱。吉门遇门迫，吉的力量打折。凶门遇门迫，凶的力量也打折——但这个"打折"是往两头去的，不一定变好。

五不遇时 + 凶格叠加

当五不遇时和一个以上凶格同时出现，叫"双重凶格"。像暴风雨里还打雷——雪上加霜。

测任何事见双重凶格，建议改时间再做。如果不能改，做好最坏准备。

格局叠加与化解

格局不是孤立的。一个盘里可能同时出现吉格和凶格。就像一天里上午晴天下午暴雨——你得分段看。

叠加的规则

龙鸟呈祥：飞鸟跌穴 + 青龙返首同时出现。至吉。
三遁并现：天遁 + 地遁 + 人遁任意两个以上。大吉。
双重凶格：太白入荧 + 五不遇时。大凶。
刑墓并见：击刑 + 入墓同现。事有大阻。
吉凶相消：吉格和凶格同现，看哪个力量更大。主要看旺衰——旺的一方占主导。

化解的思路

奇门格局的化解不是"魔法消除"。它的核心思路是"趋吉避凶"——通过选择方位、时间、行为来避开凶格的影响。

遇到白入荧：避开庚所在的方位，往丙所在的方位去。
遇到入墓：等出墓的时间（一般等1-2个时辰）。
遇到门迫：换一个时间点行动。
遇到空亡：等填实的日子再行动。

格局优先级排序

读盘的时候，格局太多怎么办？按优先级看：

用神宫的格局 > 值符宫的格局 > 时干宫的格局 > 其他宫的格局。

用神是核心。如果用神宫出了吉格，其他宫有凶格也不要紧——核心事情是好的。反过来，用神宫出了凶格，其他宫再好也有限。
