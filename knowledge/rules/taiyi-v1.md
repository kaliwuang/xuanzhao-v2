# 太乙神数判断准则 v1

## T1 — 主算>客算 → 主方占优
条件：主算数大于客算数
判断：主方（守方/己方）占优势，宜守不宜攻
反例：客算>主算则客方占优

## T2 — 主客算同数 → 僵持
条件：主算等于客算
判断：双方势均力敌，短期内分不出胜负
注意：看三基五福进一步判断

## T3 — 太乙落阳遁宫 → 阳气盛，利动
条件：太乙落在阳遁局的宫位
判断：该时段阳气旺盛，适合主动出击/开创新局
反例：阴遁则宜守

## T4 — 君基旺 → 国运/大势向好
条件：君基落在旺相宫位
判断：宏观环境有利，顺势而为容易成功
反例：君基落衰则大环境不利

## T5 — 臣基克君基 → 内部有矛盾
条件：臣基五行克君基五行
判断：团队/组织内部有分歧，需化解
化解：找到矛盾根源，调整利益分配

## T6 — 五福齐全 → 大吉
条件：三基五福中五福全部到位
判断：万事顺遂，是太乙中最吉的格局
注意：五福齐全极为罕见

## T7 — 天目克地目 → 外部压力大
条件：天目五行克地目五行
判断：外部环境对内部有压制
化解：内守为主，不宜外扩

## T8 — 主大将旺相 → 执行力强
条件：主大将所在宫位五行旺相
判断：主方执行力强，计划能落地
反例：主大将衰则有心无力

## T9 — 客大将入墓 → 客方无力
条件：客大将所在宫位为墓库
判断：客方（对手/外力）暂时无力行动
注意：入墓不是永久的，出墓后会恢复

## T10 — 太乙临择日 → 该日吉凶判断
条件：用太乙临日法判断某日吉凶
判断：太乙临吉门+吉星=宜行动；临凶门+凶星=宜静守
应用：搬家/开业/出行择日

## T11 — 阴阳遁交界 → 转折点
条件：冬至/夏至前后（阴阳遁切换期）
判断：该时段是气场转换期，重大决策需谨慎
注意：冬至后阳遁开始/夏至后阴遁开始

## T12 — 主算单数 → 速应
条件：主算为单数（1/3/5/7/9）
判断：事情发展快，短期内见结果
反例：双数则慢

## T13 — 太乙与天目同宫 → 天人合一
条件：太乙与天目落在同一宫位
判断：天时与人事高度吻合，做事容易成功
注意：此格局较少见

## T14 — 计神落空 → 计划落空
条件：计神所在宫位逢空亡
判断：原定计划容易落空，需准备备选方案
化解：提前做两手准备

## T15 — 参将生大将 → 辅助得力
条件：参将五行生大将五行
判断：副手/辅助力量强，能有效支持主将
反例：参将克大将则内部消耗
