# 姓名学判断准则 v1

## X1 — 人格吉+总格吉 → 一生顺遂
条件：人格数理为吉（如1/3/5/6/7/8/11/13/15/16/17/18/21/23/24/25/29/31/32/33/35/37/39/41/45/47/48），总格也为吉
判断：此人一生运势较顺，事业和人际关系都不错
反例：人格凶+总格凶则一生多波折

## X2 — 三才配置相生 → 天地人和谐
条件：天格→人格→地格形成五行相生链
判断：此人先天条件好，家庭支持力强，容易成功
反例：三才相克则天地人不协，人生阻力大

## X3 — 人格克天格 → 与长辈/上司关系紧张
条件：人格五行克天格五行
判断：此人容易与长辈/上司产生冲突，不服管教
化解：选择能发挥自主性的职业

## X4 — 地格克人格 → 婚姻/下属运差
条件：地格五行克人格五行
判断：婚姻容易出问题，或下属不给力
注意：地格代表36岁前运势+婚姻基础

## X5 — 外格凶 → 社交运差
条件：外格数理为凶（如2/4/9/10/12/14/19/20/22/26/27/28/30/34/36/40/42/43/44/46）
判断：此人社交运较差，容易被人误解或孤立
化解：主动经营人际关系

## X6 — 总格与人格相生 → 中晚年运好
条件：总格五行人格五行（相生关系）
判断：36岁后运势上升，越老越好
反例：总格克人格则中晚年辛苦

## X7 — 姓名中五行互补八字 → 加分
条件：姓名五格中补了八字所缺的五行
判断：姓名对八字有补救作用，运势加分
注意：这是姓名学最核心的应用价值

## X8 — 姓名中五行克八字喜用 → 减分
条件：姓名五格中五行克了八字喜用神
判断：姓名对八字有负面作用，运势打折
化解：考虑改名或用笔名

## X9 — 女性人格21/23/33 → 刚强命
条件：女性人格数理为21/23/33（这些是"首领数"，传统认为女性不宜）
判断：此女能力强但婚姻可能不顺
注意：现代社会此规则已弱化

## X10 — 复姓+双名 → 五格计算不同
条件：复姓（如司马/欧阳）或双名（如"志明"vs"明"）
判断：天格=姓氏笔画之和+1（复姓），计算方式不同
注意：单姓单名/单姓双名/复姓单名/复姓双名各不同

## X11 — 81数理循环 → 超过80要减80
条件：总格笔画数超过80
判断：减去80后取余数对应的数理
注意：如82画=82-80=2，按2的数理解读

## X12 — 三才全吉但五格有凶 → 整体中吉
条件：三才配置全吉，但个别五格为凶
判断：先天条件好但个别方面有短板
注意：三才优先于五格，三才吉是大格局

## X13 — 姓名谐音不吉 → 暗伤
条件：姓名读音有不雅谐音
判断：虽不在五格计算中，但实际影响社交和心理
注意：现代姓名学越来越重视谐音

## X14 — 公司名=人格+总格为主
条件：公司起名时主要看人格和总格
判断：人格代表公司内部运营，总格代表对外形象
注意：公司名不需要看天格地格

## X15 — 改名后3-5年才见效
条件：改名后短期内看不到变化
判断：姓名的影响力需要3-5年才能显现
注意：不要频繁改名，每次改名都是重新起步
