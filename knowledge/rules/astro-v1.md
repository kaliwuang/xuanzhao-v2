# 西洋占星判断准则 v1

## A1 — 太阳月亮上升三合 → 内外一致，人生顺遂
条件：太阳/月亮/上升星座之间形成三分相（120°）或六分相（60°）
判断：此人内外一致，不容易自我矛盾，人生相对顺遂
反例：太阳月亮对冲（180°）= 内心拉扯

## A2 — 月亮与火星四分相 → 情绪管理是课题
条件：月亮与火星形成四分相（90°）
判断：此人情绪容易爆发，需学习控制愤怒
化解：运动/体力劳动可以释放火星能量

## A3 — 金星与土星对冲 → 感情迟来但稳定
条件：金星与土星形成对冲（180°）
判断：早年感情不顺，但30岁后感情趋于稳定
注意：土星延迟但不消灭，耐心等待

## A4 — 木星过境第十宫 → 事业上升期
条件：流年木星进入本命第十宫（中天）
判断：该年事业有突破，可能升职/加薪/获得认可
应期：木星在十宫停留约1年

## A5 — 土星回归（约29.5岁）→ 人生大考
条件：流年土星回到本命土星位置
判断：29-30岁左右有重大人生考验（职业转型/关系重组/身份转变）
注意：扛过去就升级，这是成年礼

## A6 — 水星逆行在第三宫 → 沟通必出问题
条件：流年水星逆行在本命第三宫
判断：该期间沟通/交通/电子设备容易出问题
化解：重要合同避开水逆期，备份数据

## A7 — 火星在第一宫 → 行动力爆棚期
条件：流年火星进入本命第一宫
判断：该期间精力旺盛，适合开始新项目
注意：也容易与人冲突，控制脾气

## A8 — 冥王星过境第四宫 → 家庭根基重塑
条件：流年冥王星进入本命第四宫（约15-20年一次）
判断：该期间家庭结构可能剧变（搬家/父母变故/重新定义"家"）
注意：冥王星是深层转化，痛苦但必要

## A9 — 上升天蝎 → 外表冷内心热
条件：上升星座在天蝎座
判断：给人第一印象神秘/冷漠，但内心情感强烈
注意：容易吸引试探你底线的人

## A10 — 太阳第十宫 → 天生事业心
条件：本命太阳在第十宫（中天附近）
判断：此人天生追求社会地位和事业成就
注意：容易忽略家庭，需要平衡

## A11 — 金星第七宫 → 天生桃花体质
条件：本命金星在第七宫
判断：此人天生有魅力，容易吸引异性
注意：也容易陷入多角关系

## A12 — 土星第一宫 → 大器晚成
条件：本命土星在第一宫
判断：此人早年辛苦，中年后渐入佳境
注意：土星第一宫的人外表严肃，但内心有责任感

## A13 — 海王星四分月亮 → 情感迷雾期
条件：流年海王星四分本命月亮
判断：该期间容易在感情中迷失，分不清幻想和现实
化解：保持理性，不要在这期间做重大感情决定

## A14 — 木星过境第二宫 → 财运上升
条件：流年木星进入本命第二宫
判断：该年收入增加，物质生活改善
注意：木星也膨胀，别过度消费

## A15 — 日返盘太阳在第十宫 → 该年事业为重
条件：太阳回归盘中太阳在第十宫
判断：该年事业是人生主题，会有与事业相关的重大事件
应期：日返盘生日后一年内
